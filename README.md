# 晴蓝小岛 · 荒岛求生

[打开游戏](https://nornttyy.github.io/cozy-blue-island/)

桌面浏览器第一人称小岛生存游戏。采集材料、制作工具、搭建营地，潜入海水，或与朋友一起乘船探索随机群岛。无需登录。

## 操作

点击开始后锁定鼠标。WASD 移动，鼠标转头；左键采集或使用物品，空格跳跃/上浮，C 下潜，Shift 加速。B 打开背包与制作，M 地图，J 手账，1–8 或滚轮切换快捷栏，Esc 暂停并释放鼠标。

推荐使用支持 WebGL 2 和 Pointer Lock 的桌面 Chrome / Edge。部分应用内置浏览器会拒绝鼠标锁定，此时请将网址复制到独立浏览器。尚未提供手机触屏操作。

## 单人与合作

- 单人存档保存在当前浏览器的网站数据中。清除网站数据会丢失存档。
- 原网站与 GitHub 网站属于不同域名，本机存档不会自动迁移。原网站仍然保留。
- 点击“和朋友一起”创建或加入 2–4 人房间；分享房间码即可同行。
- GitHub Pages 托管游戏前端；房间由现有晴蓝小岛服务器提供，并非 GitHub 提供数据库。
- 房间保留 24 小时，共享物资与营地，和单人存档分开；目前是合作测试版，不是永久云存档。
- 联机使用昵称与角色/游戏状态，房间身份令牌仅存浏览器会话；不需要 GitHub、微信或其他账号密码。服务器暂时不可用时单人仍可游玩。

## 技术与发布

使用 Three.js、JavaScript ES Modules、WebGL 2 和 GLB 模型。所有画面与运行素材均在此仓库，无需额外安装依赖。

本地可运行 `python3 -m http.server 8894`，再打开 `http://localhost:8894/`。直接双击 HTML 不支持 ES Modules 与模型加载。本地静态服务仅用于单人；合作 API 使用原网站后端。

GitHub Pages 从 `main` 分支根目录发布，后续推送该分支会自动更新网页。

本仓库不包含生产数据库、密钥、开发者账号凭据、本地存档或旧工作区历史。Three.js 第三方许可见 [vendor/THREE-LICENSE.txt](vendor/THREE-LICENSE.txt)。公开访问不意味着授予游戏代码或美术素材额外的再许可。
